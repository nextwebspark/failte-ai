# Returns policy (template)

Replace the values in this file with your own policy after adding the skill to
your workspace.

## Changed your mind

- Window: 30 days from delivery.
- Condition: unused, with original packaging and tags.
- Refund: to the original payment method within 5 working days of the item
  arriving back at the warehouse.
- Return postage: paid by the customer, unless they choose an exchange.

## Faulty or damaged

- Window: report within 12 months of delivery.
- Outcome: free repair, replacement or full refund, the customer's choice.
- Return postage: free; send a prepaid label to the customer's email.
- Damage in transit: ask for a photo by email; no need to return the item if
  its value is under 20 (currency of the store).

## Not returnable (unless faulty)

- Personalised or made-to-order items.
- Opened hygiene products (earphones, cosmetics).
- Gift cards.

## Exchanges

- Same item in a different size or colour: free, subject to stock.
- A different item: process as a return and a new order.
