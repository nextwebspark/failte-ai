## Managed transcribers

On Fallcha.ai's managed models you pick a Google speech-to-text model (Chirp 3, Latest long or Latest short) and the caller's language under **Models & voice**. Each model lists only the languages it supports. No API key is needed. See [Models & voice](inference-providers).

## Your own providers (self-hosted)

Fallcha.ai platform supports Deepgram, OpenAI, Google, Azure Speech, AssemblyAI, Speechmatics, Cartesia, Gladia, Soniox, Sarvam, Smallest AI, Hugging Face, ElevenLabs, and Fallcha.ai transcribers. You can take a look at the providers documentation of which language to select for your language requirements. 

<Warning>
Transcriber providers receive the data needed to transcribe speech, such as call audio, language settings, keyterms, and request metadata. Review the provider's data processing, retention, model training, and regional hosting policies before using sensitive data.
</Warning>

For locally deployed or self-hosted STT models, Fallcha.ai also supports Speaches, an OpenAI API-compatible server for streaming transcription.

Example: Deepgram has their language support documentation at https://developers.deepgram.com/docs/models-languages-overview#nova-3

## Deepgram Flux language hints

With the `flux-general-multi` model, **Language hints** biases transcription toward the languages you expect callers to speak. Pick several when callers switch between known languages, for example Hindi and English. Hints are combined with the **Language** setting, and leaving both on auto-detect lets Flux detect the language on its own.

Hints only help within the languages Flux multilingual supports. They do not add new ones. See [Deepgram's language prompting guide](https://developers.deepgram.com/docs/flux/language-prompting).
